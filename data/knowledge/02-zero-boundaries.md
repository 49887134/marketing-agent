# 零分母与空数据处理

来源：项目内部知识资料；更新：2026-09-29；非官方投放规则。

## 零展现时的点击率
展现量为 0 时，CTR 的分母为 0，不能计算。接口返回 null，前端显示“—”。这不等于 CTR 为 0%。有展现但点击量为 0 时，CTR 可以计算，结果为 0，前端显示 0.00%。必须区分零值与缺少可计算条件。

## 零点击时的平均点击成本与转化率
点击量为 0 时，CPC 和本案例定义的 CVR 都不能计算，返回 null 并显示“—”。即使消费为 0，也不能把 0/0 当成 0。排查时先检查数据口径与采集时间，不应仅因一个分母为零就自动调整出价。

## 没有匹配记录与服务失败
报表筛选没有匹配记录时，返回空列表和各项总量为 0 的汇总，汇总 CTR、CPC 为 null；这属于成功查询。后端未启动、网络不通或接口异常则属于请求失败，应提示并允许重试。空数据不能伪装成服务正常获得的投放结论。
