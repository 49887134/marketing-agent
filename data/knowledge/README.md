# 投放知识资料

本目录包含 Markdown 知识资料和百度创意 CSV 明细，不是百度官方投放规则。更新时间：2026-09-30。没有退款政策或实时竞价信息。

入库读取除 README.md 外的 `.md` 和 `.csv`。Markdown 使用一级标题作为文档标题、二级标题作为片段主题；CSV 自动识别 UTF-8 或 GB18030 编码，跳过表头前的生成时间和筛选条件，自动识别至少两列的表头，并按数据行独立切片，超长记录继续拆分。来源保留相对路径，哈希追踪版本。内容存入远程 Supabase，并发送给配置的 Embedding/回答服务，不是完全本地处理。

知识资料由系统管理员统一入库，普通运行环境无需重复导入。CSV 可检索具体日期、计划和创意；查询中的日期和长数字 ID 会优先精确匹配，再按向量相似度排序。跨全表精确汇总仍应调用结构化报表接口。
